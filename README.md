# 方块世界（MC-web）

这是一个原创的浏览器体素沙盒原型，借鉴常见方块建造游戏的玩法体验。它不是 Minecraft 1.21.1 的完整实现，也不包含 Mojang/Microsoft 的原版代码、纹理、声音或其他专有素材。

## 当前功能

- Three.js 第一人称 3D 体素世界与随机地形、树木
- WASD 移动、空格跳跃、鼠标视角控制及基础方块碰撞
- 左键挖掘并收集方块，右键消耗物品放置方块
- 快捷栏、数字键/滚轮切换，以及 E 键物品栏
- 白天与夜晚的光照循环
- 世界方块与物品数量自动保存到浏览器 `localStorage`
- 重置世界并清除本机存档

## 运行

项目用浏览器 ES modules 从 CDN 加载 Three.js，需通过本地静态服务器运行，例如：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。首次进入请点击“进入世界”并允许鼠标锁定。

## 操作

| 操作 | 功能 |
| --- | --- |
| WASD | 移动 |
| 空格 | 跳跃 |
| 鼠标移动 | 转动视角 |
| 鼠标左键 | 挖掘方块并收集 |
| 鼠标右键 | 放置选中的方块 |
| 1–6 / 滚轮 | 切换快捷栏物品 |
| E | 打开物品栏 |
| Esc | 暂停/释放鼠标 |
